# TradeValidator AI

TradeValidator AI is a vision-powered trading intelligence system that analyzes chart screenshots and generates professional, structured trade insights.

Built using multimodal AI, the platform evaluates market structure, trade validity, entry quality, and risk conditions to help traders make more informed decisions.

> This tool is designed for educational and informational purposes only. It does not provide financial advice.

## Features

- AI-powered chart analysis using Gemini multimodal models  
- Structured institutional-style trade reports  
- Market structure detection (Bullish / Bearish / Ranging)  
- Trade validity assessment  
- Entry quality evaluation  
- Risk analysis based on timeframe and trading style  
- Professional verdict generation  
- Clean Streamlit interface

- Python

# Setup Instructions

## 1) Clone the Repository
```bash

git clone https://github.com/jatin-wig/Trade-Validator-AI.git
```

## 2) Install Dependencies
```bash
pip install -r requirements.txt
```

## 3) Add Gemini API Key (Required)

Create a .env file in the project root directory:

GOOGLE_API_KEY=YOUR_GEMINI_API_KEY

## Important:

Do not upload .env to GitHub

Keep your Gemini API key private

## 4) Run the App
```bash
streamlit run app.py
 ```
or 
```bash
python -m streamlit run app.py 
```
